# Create Weekly Status Report

- Use Markdown format.
- Include only these sections in order: Accomplishments, Blockers, Next Week.
- Write each section as a heading.
- Use bullet points only under each section.
- Keep the report concise and professional.
- Limit the total length to 20 lines maximum.
- Use a clear, direct tone.
- Avoid fluff words, filler phrases, and marketing language.
- Focus on completed work, current issues, and planned actions.
- Do not include tables, long paragraphs, or narrative text.
- Keep each bullet brief and actionable.
- Use plain, business-appropriate wording.
- Do not include emojis, greetings, or closing statements.
- Ensure the output is suitable for a project status update.
- Keep the structure consistent across reports.
- If no blocker exists, write: "- No blockers." under Blockers.
- If no items are planned, write: "- No planned items." under Next Week.
- Keep the total output under 20 lines including headings.
